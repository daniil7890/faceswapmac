# FaceSwapMac

**Русский** · [English](README.en.md)

Подмена лица в реальном времени на Mac (Apple Silicon) по одной фотографии. Обучать ничего не нужно.

Пайплайн: камера (AVFoundation, 720p BGRA), затем SCRFD-2.5g находит лицо и 5 точек. После этого ArcFace достаёт «личность» с фото, inswapper_128 рисует новое лицо, и оно вклеивается обратно с мягкой маской. Модели работают через ONNX Runtime с CoreML execution provider (Neural Engine/GPU). Предобработка написана на Swift и сверена с эталоном на Python.

## Установка

Требования: Mac на Apple Silicon (M1 и новее), macOS 14 Sonoma или новее, около 1 ГБ свободного места, камера (встроенная, USB или iPhone через Continuity Camera).

### Вариант 1. Готовое приложение (проще всего)

1. **Скачай приложение.** Открой страницу [Releases](https://github.com/daniil7890/faceswapmac/releases/latest) и скачай `FaceSwap-vX.Y.Z-arm64.zip`.
2. **Распакуй и перенеси в «Программы».** Дважды кликни по zip-архиву и перетащи `FaceSwap.app` в папку «Программы» (Applications).
3. **Сними карантин.** Приложение не подписано сертификатом Apple, поэтому macOS не даст его открыть двойным кликом. Открой «Терминал» и выполни:
   ```bash
   xattr -dr com.apple.quarantine /Applications/FaceSwap.app
   ```
   Другой способ: правый клик по приложению → «Открыть» → «Открыть». Если macOS всё равно ругается, зайди в «Системные настройки» → «Конфиденциальность и безопасность», пролистай вниз и нажми «Всё равно открыть».
4. **Скачай модели** (~460 МБ, один раз). В «Терминале»:
   ```bash
   curl -fsSL https://raw.githubusercontent.com/daniil7890/faceswapmac/main/scripts/download_models.sh | bash
   ```
   Модели сохранятся в `~/Library/Application Support/FaceSwapMac/models`.
5. **Запусти FaceSwap** и разреши доступ к камере, когда macOS спросит.
6. **Подожди первую загрузку.** CoreML компилирует модели под твой Mac, это до минуты. Следующие запуски проходят быстро.
7. **Выбери лицо.** Перетащи фото в левую панель или нажми «Выбрать фото…». Лучше всего подходит анфас: лицо крупно, хорошо освещено, без очков и чёлки на глазах.

### Вариант 2. Сборка из исходников

1. Поставь инструменты разработчика (полный Xcode не нужен):
   ```bash
   xcode-select --install
   ```
2. Склонируй репозиторий, скачай модели и собери приложение:
   ```bash
   git clone https://github.com/daniil7890/faceswapmac.git
   cd faceswapmac
   bash scripts/download_models.sh
   bash scripts/make_app.sh
   open build/FaceSwap.app
   ```
   Первая сборка скачивает ONNX Runtime и занимает несколько минут. Если сборка упадёт, полный лог будет в `build.log`.

### Если что-то не работает

| Проблема | Что делать |
|---|---|
| «Приложение повреждено» или не открывается | Повтори шаг 3: команду `xattr` |
| «Нет файла модели …» | Повтори шаг 4 и проверь, что в `~/Library/Application Support/FaceSwapMac/models` лежат три `.onnx` файла |
| Чёрное превью или «Нет доступа к камере» | «Системные настройки» → «Конфиденциальность и безопасность» → «Камера» → включи FaceSwap |
| «На фото не найдено лицо» | Возьми другое фото: анфас, лицо крупнее, освещение лучше |
| Низкий fps | Закрой тяжёлые приложения и подключи зарядку. На M1/M2 Air fps ниже, чем на Pro |

### Удаление

Удали `FaceSwap.app` из «Программ» и папку `~/Library/Application Support/FaceSwapMac`.

## Чтобы картинка шла в Discord/OBS/Zoom

В v0.1 своей виртуальной камеры нет: Camera Extension требует подписи Developer ID.
Пока делай так: OBS → «Захват окна» → FaceSwap, затем «Запустить виртуальную камеру».

## Ожидаемая скорость

Около 20–30 fps на M1 Pro и новее. Бо́льшую часть времени занимает inswapper.
Если тормозит, проверь в Activity Monitor → GPU/ANE, что CoreML EP подхватился.

## Метка «AI»

По умолчанию в углу превью показана метка «AI · подмена лица», её можно выключить в настройках.
Не выдавай себя за реального человека без его согласия: в большинстве стран это незаконно
(мошенничество, клевета, deepfake-законы), да и просто подло.

## Структура

- `Sources/FaceSwapMac/ImageOps.swift` — similarity-выравнивание, warp, маска, вклейка
- `Models.swift` — обёртки ONNX Runtime, чтение `emap` прямо из inswapper.onnx
- `Engine.swift` — пайплайн и сглаживание точек
- `Camera.swift`, `App.swift` — захват и SwiftUI
- `reference/` — эталон на Python (`reference_swap.py`) и порт Swift-математики для сверки

## Идеи на потом

- Нативный Core ML вместо ORT (coremltools через onnx2torch) даст ещё больше fps
- Улучшайзер лица (GFPGAN/CodeFormer) через кадр
- Camera Extension, чтобы была своя виртуальная камера
- Связка с RVCMac: голос и лицо в одном приложении

Модели: InsightFace (inswapper, ArcFace, SCRFD), лицензия только для некоммерческого использования.
